## 1. Сайт для удаления фона у картинок:
https://snapedit.app/ru/background-remover/upload <br />
Желательно, чтобы **фон был однотонным** (одного цвета) или **цвета фона и основной картинки** у которой надо убрать фон (например персонажа) **не были одинаковыми**, иначе модет удалиться часть картинки<br />
Также фон можно убрать в GIMP или других графичечких редакторах, например Paint.NET, с помощью волшебной палочки и ластика.<br />
